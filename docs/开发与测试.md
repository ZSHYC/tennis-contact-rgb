# 开发与测试

[返回 README](../README.md)

## 开发环境

```bash
conda env create -f environment.yml
conda activate tennis-contact
```

环境已存在时，进入仓库更新依赖与可编辑安装：

```bash
conda env update -n tennis-contact -f environment.yml
```

代码通过可编辑安装注册为 `tennis_contact` 包，命令行入口为 `tennis-contact`。修改 Python 文件后可以直接运行命令。

```bash
pytest -q
```

## 环境自检

检查命令入口与视频工具：

```bash
tennis-contact --help
ffprobe -version
```

检查 PyTorch 与 GPU：

```bash
python -c 'import torch; print("PyTorch:", torch.__version__); print("CUDA:", torch.cuda.is_available())'
```

`CUDA: False` 时可以使用 `--device cpu`。使用 GPU 时，确保驱动和当前 PyTorch 运行库能够正常工作。

## Python接口

网络输入是模型设备上的 `uint8 [T, 3, H, W]` RGB 张量。可以从原视频读取指定的原生帧号后调用前向：

```python
from pathlib import Path

import numpy as np
import torch

from tennis_contact.data import read_frames
from tennis_contact.model import load_model

model, _ = load_model("weights/best.pt", device="cpu")
rgb = read_frames(Path("data/video/match.mp4"), np.array([0, 1, 2]))

with torch.inference_mode():
    output = model(rgb, precision="fp32")

print(output["eventness_logit"].shape)  # [T]
print(output["type_logits"].shape)     # [T, 2]
```

完整视频的采样、前向和结果解码优先使用 `tennis-contact predict`；该命令负责组织上下文和恢复原生帧时间轴。

直接调用 `predict_video` 时，传入模型会原地合并 BatchNorm、冻结参数并转换到目标设备。该实例随后只用于推理；若还需训练或保存原始结构的 checkpoint，请重新调用 `load_model`。
