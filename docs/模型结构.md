# 模型结构

[返回 README](../README.md)

TennisContactNet 将连续 RGB 画面转换为击球和落地事件分数。网络包含一个视频视觉骨干、空间局部状态读出、双向时间模型和两个输出头，总参数量为 **6,797,590**。

## 输入与时间窗口

| 项目 | 当前实现 |
| --- | --- |
| 视频输入 | MP4 / MOV，读取真实 PTS |
| 网络图像输入 | `uint8 [T, 3, 448, 796]`，RGB 通道顺序 |
| 像素处理 | OpenCV `INTER_AREA` 缩放、内存 JPEG95 编解码 |
| 归一化 | 像素除以255，各通道减0.45、除0.225 |
| 时间采样 | 以视频第一帧 PTS 为起点，按30Hz逻辑网格取最近原生帧 |
| 核心输出窗口 | 100个逻辑时刻 |
| 上下文 | 核心窗口前后最多各28个逻辑时刻 |
| 首尾处理 | 保留实际有效时刻，边界处不填充无效帧 |

30Hz 描述的是网络的采样网格。视频自己的帧率和时间轴由输入视频决定。相邻逻辑时刻可以映射到同一原生帧，模型仍保留这些重复时刻以维持时间间隔。

## 视觉编码

视觉骨干使用 PyTorchVideo 的 X3D-S。逐帧通道注意力 FrameSE 为每个时间位置计算独立的通道权重。空间池化保留时间维度，得到每个时刻的 **2048维全局特征**。

同时，S3 阶段提供 `[1, 96, T, 28, 50]` 空间特征。每个时刻的1400个空间格被映射为空间关注分布，从中读取局部视觉状态。

## 68维空间局部状态

| 状态 | 维度 | 计算方式 |
| --- | ---: | --- |
| 局部外观 | 64 | 空间注意力加权读取，经线性投影、LayerNorm 和 presence 门控 |
| soft x / y | 2 | 关注分布在归一化空间网格上的加权重心 |
| 归一化熵 | 1 | 关注分布的熵除以空间格数量的对数 |
| presence | 1 | 空间平均特征经线性层与 sigmoid 得到的存在性估计 |
| 合计 | **68** | 按时刻拼接 |

状态通过 `68 → 128 → 2048` 的适配网络，与全局特征相加后送入时间模型。空间关注分布是内部事件表征，soft x / y 不作为可直接使用的球定位结果。

## 时间建模与分数

双向 GRU 每个方向 hidden size 为256，输出512维时序表征。事件强度头输出一个 eventness logit，类别头输出 hit / bounce 两个 logits。

最终逐类分数为：

$$
s_k(t)=\sigma(e(t))\cdot\operatorname{softmax}(z(t))_k,
\qquad k\in\{\mathrm{hit},\mathrm{bounce}\}.
$$

这些分数用于找峰、阈值过滤和事件评价。模型需要事件前后的上下文，适用于离线视频分析。

## 完整时间轴输出

每个窗口只贡献核心区域的输出，上下文区域提供计算信息。重复采样到同一原生帧的 logits 先取平均，再按真实 PTS 线性插值到完整原生帧轴，最后计算逐类分数。

事件解码对两类分别执行局部峰提取、阈值过滤和半径5帧的 NMS。平顶峰选择最左端，同分 NMS 优先较早帧。输出字段和匹配规则见 [推理与评价](推理与评价.md)。

## 精度与训练状态

- 推理使用 FP32，并关闭 TF32。
- `train --precision bf16` 仅对视觉骨干使用 BF16；空间读出、GRU、logits 和损失保持 FP32。
- `train --precision fp32` 使用完整 FP32 路径。
- 模型进入训练模式时，BatchNorm 统计保持冻结，Dropout 正常启用。
