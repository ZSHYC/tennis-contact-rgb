# 独立交付设计与实施记录

本次交付将研究模型 EO 命名为 TennisContactNet，整理到独立目录，包含最佳权重、父初始化权重、原视频数据处理、训练与恢复、完整时间轴推理、事件评价及中文使用说明。用户已明确授权实施和发布公开 GitHub 仓库。

采用直接整理核心数学和已训练参数的方式。复制整个研究目录会继续依赖历史实验；重新设计网络则无法交付同一个最佳模型。因此不采用这两条路径。

原视频直接读取，时间来自真实 PTS；缩放后在内存完成 JPEG95 编解码，以保持历史模型的输入分布，但不创建图像缓存。保留数据清单、视频级 split 和必要训练断点，不引入文件指纹、哈希、动态源码加载或旧模型分派。

实施顺序：

1. 整理独立网络并导出 EO 与父模型参数，检查参数数量、严格加载、真实输入前向对照和梯度。
2. 整理 PTS 采样、标注解析和固定视频 split，检查不均匀时间轴、重复采样、首尾窗口及真实视频读取。
3. 整理原训练目标、优化器和断点恢复，检查单次更新与连续／恢复学习状态。
4. 整理完整时间轴还原、找峰、NMS、一对一评价及 validation 阈值选择，检查可区分失败的构造反例。
5. 完成中文文档、真实命令 smoke 和独立审阅后，创建公开 GitHub 仓库并核对远端文件与权重。

已完成的历史训练与事件指标按原值记录。本次不重新训练完整历史链，也不把短 smoke 当作完整成绩复现；独立交付的训练可以从父权重或最佳权重继续，重新训练的实际效果须重新评价。
